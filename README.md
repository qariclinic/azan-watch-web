# Azan Watch — ویب ورژن

ایپ کی تمام فائلیں سٹیٹک ہیں؛ کسی سرور کوڈ کی ضرورت نہیں۔ `index.html` کھولنے والا کوئی بھی ہوسٹ چلے گا۔

## GitHub Pages پر چلانا (مفت HTTPS)
1. ان تمام فائلیں (بشمول `.nojekyll`) ریپو میں رکھیں۔
2. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** / **(root)** ← Save۔
3. ایک دو منٹ بعد ایڈریس اوپر Pages کے صفحے پر دکھائی دے گا۔
4. موبائل پر اس ایڈریس کو کھول کر براؤزر مینو سے **Add to Home screen / Install app** دبائیں؛ یہ بالکل ایپ کی طرح چلے گی اور آف لائن بھی۔

## مقامی طور پر آزمانا
`npx serve .` یا `python -m http.server 8000` چلا کر `http://localhost:8000` کھولیں۔

## نوٹ
- اذان کی آواز کے لیے صفحے پر ایک بار کلک ضروری ہے (براؤزر کی پابندی)۔
- GPS اور انسٹال کے لیے HTTPS لازمی ہے (GitHub Pages پر خود مہیا ہوتا ہے)۔
- اوقات فلکیاتی حساب سے ہیں؛ مقامی جنتری سے ملا لیں۔
